# dawnkperry.com

Dawn K. Perry's website. Plain HTML, hosted free on GitHub Pages.

- `index.html`: the whole site
- `images/`, `files/`: photos and PDFs, copied once from the old Squarespace site by the "Fetch assets" action (`assets.json` lists them, `fetch_assets.py` downloads them)
- `404.html`: also redirects old Squarespace links (/work, /new-page-2, /writings/…) to the right section

To edit: open `index.html` on GitHub, click the pencil, change the text, commit. The site updates in about a minute.
To swap a photo: upload a new file with the same name into `images/`.
